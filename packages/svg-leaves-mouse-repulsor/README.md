# SVG Leaves + Mouse Repulsor

A Pen created on CodePen.

Original URL: [https://codepen.io/abberg/pen/oEVwpw](https://codepen.io/abberg/pen/oEVwpw).

A dynamically created bed of svg leaves that get pushed by mouse movement.
Imported into Mouse Trailers with locally bundled dependencies, pointer/touch input, responsive layout, and automatic thumbnails. Original files remain untouched.
