Infinite Circus

Jetfire, a VF-1S Valkyrie, flees, boosts, and transforms to shoot down an endless Itano Circus of homing missiles. Built with React Three Fiber, drei and @react-three/postprocessing, bundled with Vite.

- `npm run dev --workspace=infinite-circus` serves it with hot reload at http://127.0.0.1:5190.
- `npm run build --workspace=infinite-circus` writes `dist/`, which the site build copies to `/sketches/infinite-circus/`.

Code is in `src/`; the models, skins, sky and cloud texture it loads at runtime are in `public/`.
