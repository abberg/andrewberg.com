# A Thousand More — June 9, 2015

Imported from `doathousandmore.com/public/sketches/6-9-2015_10-15-3`, leaving the original untouched. Preserves the moving orb, illuminated rings, bloom, and light rays.

Three.js r71 is bundled locally. Thumbnail mode uses 120 fixed simulation steps and a fixed animation time. Post-processing follows the canvas dimensions, resizes both composers, disposes replaced buffers, and composites the completed occlusion pass.
