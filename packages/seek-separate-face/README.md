# Seek and Separate, Face Target

Imported from `Archive/steering behaviors/seek separate face`, leaving the original folder untouched. The original bundled Three.js and helper scripts are kept as they were.

Run `npm run dev --workspace=seek-separate-face` to start it independently. The social buttons, Open Graph image, and Google Analytics snippet were removed. `js/thumbnail.js` drives thumbnail mode: it seeds `Math.random`, runs 240 frames on a virtual clock, then freezes the scene for capture.
