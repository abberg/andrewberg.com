# Succulent Wall

A Pen created on CodePen.

Original URL: [https://codepen.io/abberg/pen/bQwbGV](https://codepen.io/abberg/pen/bQwbGV).

Dynamically generated grid of succulents using paper.js. Each plants petal shape generated with superformula and laid out in a phyllotaxis spiral.
Imported into the Florals section with locally bundled dependencies, responsive regeneration, and seeded automatic thumbnail capture. The original ZIP is untouched.
