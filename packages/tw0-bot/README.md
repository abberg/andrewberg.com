Tw0 Bot

A grid of robots that fills the window, built from randomly placed rectangles. Each robot is coloured with a scheme drawn from mecha in Gundam, Macross and The Five Star Stories, dealt from a shuffled deck so none repeats until all are used; hover a robot to see which. The schemes are in `src/palettes.js`. A background without 3:1 contrast against its robot's main colour is darkened toward the scheme's backing colour until it has it. Add `?layout=pair` for the earlier split view: a white robot on purple with orange, teal and yellow accents, beside a dark one on warm cream with indigo, purple and pink accents.

For each robot, every load generates the left half of a body from randomly sized parts (head, chest, shoulders, arms, waist, hips, legs and feet), proportioned after one of six archetypes: heroic, brute, lanky, tank, knight and big-head. The legs are then pushed apart and the arms out from the body until there is a clear gap, stretching the hips and shoulders to stay attached. Poisson disk sampling then scatters points across it, and each point inside the body gets a rectangle, mirrored to make the other half. Each robot builds itself as its tiles rain down from above, easing into place with a slight overshoot in random order, with the dark backing fading in once the last tile lands. The robots start in a diagonal wave from the top left. Then every 2.5 seconds a robot falls away, taking the cells in a shuffled order, its cell fades to a new scheme's background, and a new robot rains down in its place (all skipped when reduced motion is on). Add `?order=feet` to land the tiles mostly from the feet up instead of in random order. Reload for new robots, or add `?outline=svg` to use the original hand-drawn outline in `public/outline.svg`. Built with two.js, bundled with Vite.

Imported from `tmp/tw0-bot`, a 2021 sketch that ran on wmr. The dependencies are updated to current versions; the generated body is new.

- `npm run dev --workspace=tw0-bot` serves it with hot reload at http://127.0.0.1:5192.
- `npm run build --workspace=tw0-bot` writes `dist/`, which the site build copies to `/sketches/tw0-bot/`.
