# Untitled 001

Imported from `untitled1 sound`, preserving the supplied models, textures, audio, libraries, and credits. The source folder is untouched.

Run `npm run dev --workspace=untitled-001` to start it independently. The site build publishes `/experiments/untitled-001/`, generates a thumbnail, and lists it under Vignettes.

Drag to move the camera and change the soundtrack volume. A “Drag to scroll” prompt overlays the scene until the first press or touch. That interaction starts the audio (on release for touch). The old Google Analytics snippet was removed; input now supports pointer events. The original bundled rendering libraries are retained for compatibility.
