# A Thousand More — June 6, 2015

Imported from `doathousandmore.com/public/sketches/6-6-2015_22-52-52`, leaving the original untouched. Preserves the nested rotating shells, pink core, shadows, and light rays.

Three.js r71 is bundled locally. Thumbnail mode uses seeded randomness and 120 fixed simulation steps. Post-processing uses the canvas dimensions, resizes both composers, disposes replaced buffers, and composites the completed occlusion pass.
